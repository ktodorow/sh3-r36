# Silent Hill 3 R36S port

Terms for bringing Silent Hill 3 to R36S and assessing finished game experience.

## Language

**Full port**:
Complete playable game on target handheld, including campaign, original videos, audio, controls and save/load.
_Avoid_: Prototype, proof of life

**Internal resolution**:
Size of game image before scaling to handheld screen.
_Avoid_: Native resolution when referring to game rendering

**Output resolution**:
Size of image displayed on handheld screen.
_Avoid_: Internal resolution when referring to screen output

**Game data**:
Original game files required to play Silent Hill 3.
_Avoid_: Port package

**PortMaster package**:
Installable port files used to launch game through PortMaster.
_Avoid_: Game data
